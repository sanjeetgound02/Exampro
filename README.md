# ExamPro - Online Examination System

## Project structure

- `index.html` - login page
- `dashboard.html` - student dashboard
- `exam.html` - examination page
- `result.html` - submitted exam result
- `results.html` - result history
- `profile.html` - student profile
- `css/` - all stylesheets
- `css/js/` - all JavaScript files

## Run locally

Open the project with VS Code Live Server and launch `index.html`.

Demo accounts in `css/js/auth.js`:
- Admin demo: `admin@exam.com` / `admin123`
- Student demo: `student@exam.com` / `student123`

## GitHub Pages

Upload the contents of this folder to a GitHub repository with `index.html` in the repository root, then enable GitHub Pages from Settings -> Pages.
